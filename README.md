# CCC — CoolColorCursor

**CCC (CoolColorCursor)** — это легкая и стильная утилита для Windows, которая добавляет кастомный неоновый шлейф к движению вашего курсора мыши.

Приложение создано для тех, кто хочет добавить эстетики и индивидуальности своему рабочему столу, сделать движение курсора более плавным и заметным, или просто украсить повседневную работу за ПК.

---

### Основные возможности:

* **Кастомизация цвета:** Поддержка градиентов (переход между двумя выбранными цветами), удобное цветовое колесо, готовые палитры и сохранение истории любимых цветов.
* **Высокая производительность:** Эффект автоматически подстраивается под частоту обновления вашего монитора (60 Гц, 144 Гц, 240 Гц и выше) для максимальной плавности.
* **Гибкая настройка:** Изменение толщины шлейфа и скорости его исчезновения в реальном времени.
* **Работа поверх всех окон:** Оверлей отображается поверх всех приложений и игр, не мешая кликам (пропускает нажатия через себя).
* **Удобное управление:** Работа из системного трея, возможность автозапуска вместе с Windows и лаконичный интерфейс.

---

### Как скачать и запустить:

1. Посмотрите на **правую колонку** главной страницы этого репозитория на GitHub.
2. Найдите блок **Releases** и нажмите на последнюю (самую верхнюю) версию.
3. На странице релиза прокрутите вниз до блока **Assets** и нажмите на файл **CCC.exe**, чтобы скачать его.
4. Перенесите скачанный файл в удобную папку и дважды кликните по нему для запуска (установка не требуется).

---

### Использованные технологии:
* Python 3
* PyQt5 (GUI & Graphics)
